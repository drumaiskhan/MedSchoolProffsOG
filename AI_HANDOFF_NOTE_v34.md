# AI Handoff Note v34 — subject icons, landing page, dark mode, phone tab bar

Base = the GitHub `MedSchoolProffsOG-main` zip. The student UI modernisation from
the v33 zip was ported onto it (19 files: index.css, lib/shared.tsx and 17
pages). `netlify.toml` / `netlify.admin.toml` are the GitHub (your edited) ones,
untouched.

## 1. Automatic subject icons
- `frontend-student/src/lib/subject-icons.tsx` — `resolveSubjectIcon(name)`,
  `<SubjectIcon name iconUrl size />`, `<SubjectWatermark />`. Keyword rules map
  a subject NAME to an icon + hue (bone = anatomy, microscope = physiology, DNA
  = biochemistry, test tubes = pathology, pill = pharmacology, bug =
  microbiology, fingerprint = forensic, users = community medicine, plus
  surgery, paeds, OB/GYN, eye, ENT, skin, psychiatry, radiology, anaesthesia,
  dental (custom tooth), respiratory (custom lungs) and more). Unknown names
  get a stable fallback icon/colour. Rules are ordered — specific before
  general (`oral pathology` before `pathology`). Add new subjects by adding a
  rule in `RULES`.
- An uploaded subject thumbnail (`iconUrl`) still wins; nothing needs uploading.
- Used on: Subjects cards, Topics header banner, Progress "Accuracy by
  subject", module cards with no thumbnail (only when the module name matches).
- The admin app is NOT changed (its subject upload field still works).

## 2. Landing page + sign-in panel
- `Home.tsx`, `lib/landing-visuals.tsx` (Aurora, HeroStage, SubjectMarquee,
  GlossIcon, AuthShowcase), `lib/motion.tsx` (Reveal, useParallax,
  SpotlightCard), CSS block at the end of `index.css`.
- Depth is faked with gradients/shadows and plain 2D translate/scale ONLY — no
  perspective/rotateX/rotateY (index.css flip-card note: real 3D transforms
  corrupted paint on one GPU). All motion is off for prefers-reduced-motion.
- The sample MCQ / "7-day streak" / accuracy ring in the hero are illustrative
  mock UI, not live data.

## 3. Dark mode
- `lib/theme.ts`: in dark mode the light default surface colours are no longer
  forced inline (they beat `.dark` and left a light page). Surface colours the
  admin CUSTOMISED are still applied; a too-dark brand primary is lifted so it
  stays readable.
- `src/dark-compat.css` is GENERATED by `tools/gen-dark-compat.mjs` (remaps the
  ~57 fixed pale `bg-[#…]/text-[#…]/border-[#…]` colours). Re-run
  `node artifacts/frontend-student/tools/gen-dark-compat.mjs` after adding new
  hard-coded colours.
- Dark mode is still the admin's global Light/Dark switch (Design & Branding);
  there is no per-student toggle.

## 4. Phone bottom tab bar
- `MobileTabBar` in `lib/shared.tsx`: Home, Blocks, Exams, Cards, More (opens the
  sidebar). Hidden on md+ and in focus mode (practice/exams/reader). Shows the
  same trial lock as the sidebar. Content gets extra bottom padding on phones.

## Other
- `.gitignore` in the GitHub zip was UTF-16 with PowerShell wrapper lines (git
  ignores such a file); re-saved as plain UTF-8 with the same rules.

## Verified / not verified
- `pnpm run build:student` passes. Pages were checked in headless Chromium with
  a mocked API (landing, login, subjects, topics, dashboard, several pages in
  dark mode, phone layout).
- NOT tested against the real API/data, real subject names, or real devices
